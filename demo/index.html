AI 成本换算助手

自动把网页里的美元价格换算成人民币、把 K/M/B 大数换算成中文读数，刷一眼就知道 API 调用和海外服务到底要花多少钱。

安装脚本 GitHub 仓库 需要 Tampermonkey / Violentmonkey

自动识别

扫描页面文本，美元价格换成人民币、K/M/B 大数换成中文读数，动态内容也能捕捉。

实时汇率

自动获取 USD/CNY 汇率，本地缓存 7 天，失败时回退默认汇率。

非侵入式

不修改网页原有内容，灰色小字标注换算结果，悬停或点击可查看多币种浮窗。
